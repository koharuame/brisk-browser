## ทำไมต้อง Brisk

- **บล็อกโฆษณาในตัว** บล็อกโฆษณาและตัวติดตามก่อนโหลด ไม่ต้องลงส่วนขยายเพิ่ม และเตือนเว็บมัลแวร์หรือฟิชชิงก่อนเข้า
- **พักแท็บอัตโนมัติ** แท็บที่ไม่ได้ใช้จะค่อยๆ คืนหน่วยความจำให้เครื่อง กลับมากดเมื่อไรก็อยู่ที่เดิม
- **เป็นส่วนตัวตั้งแต่ต้น** ไม่มี telemetry ประวัติ บุ๊กมาร์ก และรหัสผ่านอยู่ในเครื่องคุณเท่านั้น มีแท็บส่วนตัวและแยกโปรไฟล์ได้
- **ตัวจัดการรหัสผ่าน** เข้ารหัสด้วยรหัสผ่านหลักของคุณ
- **จัดหน้าต่างได้ตามใจ** ดึงแท็บออกเป็นหน้าต่างใหม่ ลากกลับเข้าหน้าต่างอื่น และจัดกลุ่มแท็บ
- **รองรับส่วนขยายจาก Chrome Web Store**
- **อัปเดตในตัว** แอปตรวจหาเวอร์ชันใหม่ให้เอง กดอัปเดตจากหน้าตั้งค่าได้เลย
- **ภาษาไทยและอังกฤษ**

## ติดตั้ง

1. ดาวน์โหลด `Brisk_<เวอร์ชัน>_Setup.exe` จากหน้า [Releases](https://github.com/koharuame/brisk-browser/releases/latest)
2. เปิดไฟล์แล้วทำตามขั้นตอน ตัวติดตั้งจะตรวจเครื่องให้ก่อนว่าพร้อมใช้ Brisk ไหม

> ตอนนี้ตัวติดตั้งยังไม่ได้เซ็นดิจิทัล Windows อาจเตือนว่า "Windows protected your PC" ให้กด **More info → Run anyway**

**ความต้องการของระบบ:** Windows 11 (64 บิต), Microsoft Edge WebView2 Runtime (ตัวติดตั้งจะลงให้ถ้ายังไม่มี), พื้นที่ว่างอย่างน้อย 100 MB

## English

**Brisk** is a lightweight, privacy-first browser built on Rust and the WebView2 engine that ships with Windows 11.

- **Built-in ad & tracker blocking**, plus malware and phishing warnings
- **Sleeping tabs** give memory back while you're not using them
- **Private by design**: no telemetry; history, bookmarks and passwords stay on your PC; private tabs and separate profiles
- **Password manager** encrypted with your master password
- **Tear tabs off** into their own windows, drag them back, **group tabs**
- **Chrome Web Store extensions**
- **Built-in updates** from Settings → About
- Thai and English interface

**Install:** download `Brisk_<version>_Setup.exe` from [Releases](https://github.com/koharuame/brisk-browser/releases/latest) and run it. The installer is not code-signed yet, so Windows SmartScreen may warn you: choose **More info → Run anyway**.

**Requirements:** Windows 11 (64-bit), Microsoft Edge WebView2 Runtime (installed for you if missing), 100 MB free disk space.
