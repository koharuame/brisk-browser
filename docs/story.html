Why Brisk exists

Browsers kept getting heavier. Each one shipped its own copy of a web engine, asked you to sign in, and quietly reported how it was used. Opening a news article meant downloading a few dozen companies' scripts along with it.

Windows 11 already includes a modern web engine, Microsoft Edge WebView2, kept up to date by Windows itself. Brisk started in November 2026 with a simple question: what if a browser used that engine, and spent its own effort only on the things that make browsing feel fast?

That turned out to be two things. Don't load what nobody asked for, and let the tabs you aren't looking at rest. Everything else in Brisk is there to stay out of the way.

Brisk is made by one person, measured on real websites, and built to be used every day.

Koharuame, maker of Brisk

What Brisk holds to

  • No telemetry

    Brisk doesn't report what you do, what you visit, or how you use it. Not anonymously, not in aggregate, not at all.

  • No account

    There's nothing to sign in to. Your data is files on your PC, and it's yours to back up or delete.

  • Nothing running in the background

    When you close Brisk, it's closed. No updater service, no helper left behind.

  • Measured, not claimed

    Performance changes ship only when they make Brisk faster or lighter on real sites, and the numbers are published.

How Brisk is built

Small parts, each chosen for one reason.

Microsoft Edge WebView2

The web engine that ships with Windows 11 and updates with it. Sites work as they do in Edge, and Brisk doesn't carry its own copy.

Rust

Brisk's own code — blocking, sleeping tabs, the password vault — is written in Rust, for speed and memory safety.

Tauri

The framework that holds the windows and the interface together, in a few megabytes instead of a few hundred.

adblock-rust

The same filtering engine Brave uses, checking each request in a fraction of a millisecond.
