0.1.0 November 2026 Latest

Brisk's first release

A light, private browser for Windows 11, built on the web engine Windows already has.

New

  • Ad and tracker blocking on every request, with EasyList, EasyPrivacy, EasyList Thailand and uBlock Origin's filter lists, and a per-site switch in the shield.
  • Malware and phishing warnings from lists kept on your PC, and HTTPS first with a warning before any unencrypted connection.
  • Sleeping tabs in four steps, with a memory budget, a never-sleep list, battery saver and a task manager (ShiftEsc).
  • Tear tabs off into their own windows and drag them back; tab groups with names and colors; pinned tabs; every window restored on restart.
  • Private tabs and profiles with separate cookies and sign-ins; tracking prevention, Global Privacy Control and per-site permissions.
  • Password manager with an encrypted vault, a password generator and CSV import.
  • Chrome Web Store extensions, verified before install and switchable per profile.
  • History, bookmarks and downloads in one library, with search as you type and bookmark import and export.
  • Brisk Setup, which checks your PC before installing, and built-in updates, each one signature-checked.
  • Light and dark themes, nine color themes, and an English and Thai interface.
